# The Muze

Live at https://thecosmickitchen.github.io/The-Muze/

Free daily creative prompts, served as plain static pages on GitHub Pages. No build step and no server. A sister site to [The Puzz](https://thecosmickitchen.github.io/The-Puzz/).

- `index.html`: today's set, plus a shelf of what you've written lately

Words
- `blackout.html`: blackout poetry. One page from a public-domain novel each day; tap words to keep them, then black out the rest.
- `haiku.html` (Haiku Hunt): find a 5-7-5 haiku in a different novel page, picking words (or snipped parts of words) in any order. The syllable counter guesses; tap a count to correct it.
- `cutup.html`: eighteen strips cut from public-domain poems (no more than three per poet). Paste up to ten into a new poem, reorder them, cross words out.
- `fridge.html`: fridge-magnet poetry. A daily pile of about 70 magnets, including a handful of theme words; drag them onto the door.
- `sixwords.html`: a six-word story that has to use today's word.
- `palette.html` (Palette Walk): five colours; name each one and give it a line.
- `strip.html` (Speech Bubbles): a three-panel comic strip cut from three public-domain artworks, with a daily title and empty bubbles. Write the dialogue; move bubbles, aim their tails, switch between speech, thought and caption, or add more.

Pictures
- `paint.html` (Daub): a painting prompt, a five-colour palette and an optional twist. Brush, fill, undo.
- `oneline.html`: draw today's subject in one continuous line. Lifting the pen ends it.
- `shape.html` (Shape Seed): a random red squiggle to turn into something.
- `corpse.html` (Exquisite Corpse): head, body and legs on three days in a row. Each day shows only the strip below yesterday's fold; after the legs you see the whole creature.
- `pixel.html` (Pixel Postcard): 16×16 pixels, four colours, one subject.
- `collage.html`: three public-domain artworks a day. Cut pieces out with freehand, polygon, box or oval selection (zoom in up to 4× for fiddly bits), or take the whole picture. Then arrange them with drag handles, two-finger pinch, sliders, nudge buttons or the keyboard; flip, layer, copy, delete, or delete all. The cut-and-paste tools live in `cutpaste.js` and `cutpaste.css` so other pages can reuse them.

Everything can be saved as a PNG. Every prompt is picked in the browser from a seed. The daily seed is the date, so everyone gets the same prompt. "Another one" uses a random seed, which appears in the URL hash so a prompt can be shared. Work is saved in `localStorage` on your device.

Shared code lives in `muze.css` and `muze.js` (seeded random, saves, header, drawing canvas, text-card images, syllable guesser, palettes and subjects).

## Data

All source material is public domain. Each file is generated by a script in `tools/`:

- `data/pages.js` (Blackout, Haiku Hunt): 393 passages from 16 Project Gutenberg novels. Download the plain-text files into a folder as `<id>.txt` (from `https://www.gutenberg.org/cache/epub/<id>/pg<id>.txt`), edit the list in the script, then run `node tools/build-pages.mjs path/to/folder`.
- `data/lines.js` (Cut-up): 1,266 lines from 9 poets on Project Gutenberg. Same steps with `node tools/build-lines.mjs path/to/folder`.
- `data/art.js` and `art/` (Collage, Speech Bubbles): 149 public-domain works from the [Art Institute of Chicago](https://www.artic.edu/open-access) (CC0 images), copied in at 600px wide. Run `node tools/build-art.mjs`.
